# Materium API

REST API for the Materium raw material and supplier comparison platform.

## Tech Stack

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL

## Features

- Supplier management
- Raw material management
- Cost comparison
- Business rules for supplier analysis
- Relational data modeling

## Setup

npm install

# configure environment variables
cp .env.example .env

npm run start:dev
